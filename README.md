# ⚡ TechBrief

A modern, responsive technology editorial website designed to present AI, software, startups, gadgets, and emerging technology stories through a clean, premium interface.

## ✨ Features

* 📰 Modern tech editorial homepage
* 🔥 Trending stories section
* 🤖 AI & Intelligence deep-dive section
* 💻 Software, startups, and gadgets categories
* 🏷️ Category filtering
* 🔍 Interactive story search
* ♡ Save/bookmark interaction
* 📖 Article reading modal
* 🌙 Dark/light mode
* 📩 Newsletter subscription interaction
* 📱 Fully responsive design
* 📱 Mobile navigation menu
* 🔔 Toast notifications
* ✨ Animated CSS-based visual elements
* 🎨 Editorial-inspired premium UI

## 🛠️ Technologies Used

* **HTML5** — Semantic website structure
* **CSS3** — Responsive design, animations, layouts, and visual effects
* **JavaScript** — Filtering, search, modal interactions, theme switching, navigation, and notifications
* **Google Fonts** — Manrope & DM Mono

## 🎨 Design

TechBrief uses a dark editorial-inspired visual language combined with:

* Deep black tones
* Warm off-white backgrounds
* Electric lime accent
* Minimal typography
* Editorial spacing
* Rounded content cards
* CSS-generated technology visuals

The design was intentionally created to feel different from a traditional dashboard or corporate website.

## 📱 Responsive Design

The website is optimized for:

* Desktop
* Laptop
* Tablet
* Mobile

The layout automatically adapts navigation, story cards, hero content, newsletter sections, and article views for smaller screens.

## ⚙️ Interactive Features

JavaScript powers several interactive elements:

* Dark/light theme toggle
* Search panel
* Story filtering
* Save buttons
* Article modal
* Newsletter feedback
* Mobile navigation
* Toast notifications
* Active navigation states

## 🚀 How to Run

No installation or build process is required.

Simply open:

```text
index.html
```

in a modern web browser.
